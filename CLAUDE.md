# Interf CLI

Open-source CLI for the Agent Onboarding Protocol. Published as `interf` on npm.

## Project

- **Package**: `interf` (npm, unscoped)
- **Repo**: github.com/interf-labs/cli
- **Protocol repo**: github.com/interf-labs/agent-onboarding-protocol
- **License**: MIT
- **Company**: Interf, Inc. (interf.com)

## Architecture

Skills-based CLI — installs SKILL.md files to coding agents (Claude Code, Codex, Cursor, Goose) that teach them how to declare onboarding contracts and preview enterprise rollouts.

No Agent SDK dependency. No network calls. No code execution.

### Key directories

- `src/` — TypeScript source (commands, lib)
- `skills/` — Bundled SKILL.md files (protocol, declare, preview) — compatible with Vercel Skills format
- `dist/` — Compiled output (generated by `npm run build`)

### Skills

| Skill | Purpose |
|---|---|
| `declare` | Declare an onboarding contract (interf.yaml) |
| `preview` | Preview enterprise rollout against company profiles |
| `protocol` | Agent Onboarding Protocol spec + canonical dependency types |

### Commands (visible)

- `npx interf` — Auto-detect agents, install all skills
- `interf declare` — Install declare + protocol skills
- `interf validate` — Validate an interf.yaml onboarding contract

### Commands (hidden stubs, coming soon)

- `interf publish` — Publish contract to registry
- `interf simulate` — Cloud-powered simulation
- `interf login` / `interf logout` — Authentication

### Contract format (interf.yaml)

```yaml
name: solution-name
version: 0.1.0
description: What the solution does

requirements:
  - what: Plain English — what you need
    ready: How enterprise verifies it's done

optional:
  - what: Nice-to-have dependency
    ready: How to verify
```

### Stack

- TypeScript (ES2022, NodeNext)
- yargs (CLI framework)
- zod (schema validation)
- yaml (parsing)
- chalk (output formatting)
- vitest (testing)

## Commands

```bash
npm run build       # Compile TypeScript
npm test            # Run tests
npm publish         # Build + publish to npm
```

## Conventions

- Keep dependencies minimal (4 production deps)
- No fake API endpoints — hide stub commands from --help
- Skills are the primary interface — the CLI installs them, agents use them
- Skills follow Vercel Skills format (SKILL.md with YAML frontmatter)
- Terminology: "declare" (verb), "onboarding contract" (artifact), "requirements" (schema field)
